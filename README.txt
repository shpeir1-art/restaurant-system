
ИНСТРУКЦИЯ

1. Установите Node.js 20+

UBUNTU:
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

-----------------------------------
ЗАПУСК BACKEND
-----------------------------------

cd server
npm install
node index.js

-----------------------------------
ЗАПУСК FRONTEND
-----------------------------------

cd client
npm install
npm run dev -- --host
